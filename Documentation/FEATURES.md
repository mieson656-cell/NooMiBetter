# Feature map

## Gameplay
- Bar and Tumbling modes
- Ragdoll movement, grab/release actions and trick scoring
- Landing grades: PERFECT, CLEAN and ROUGH
- Reward coins for clean execution

## Customization
- Texture Studio with generated patterns and image import
- Audio Lab for custom music and catch sounds
- Cosmetic shop, wallet and inventory
- Theme and performance settings

## Creation and social
- Map Workshop for user obstacle layouts
- Replay recording and playback
- Multiplayer rooms with synchronized player state
- Plugin API is a future extension point, not yet a stable public SDK

## Maturity
This is a prototype feature map. Each system requires Unity Editor integration and device testing before being called release-ready.
